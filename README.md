# Clockwork (Fabric, Minecraft 26.2)

Right Shift = GUI. End = panic (disables every module). Left-click a module to toggle, right-click for settings.

## Build
Needs JDK 25. 26.x is unobfuscated, so there is no mappings line.
1. Copy `gradlew`, `gradlew.bat` and `gradle/wrapper/` from the official Fabric template (or run `gradle wrapper --gradle-version 9.5.1`).
2. `./gradlew build` -> `build/libs/clockwork-1.0.0.jar`
3. Check versions in `gradle.properties` against https://fabricmc.net/develop/ if the build can't resolve them.

## Modules
- StorageFinder: chests, trapped chests, barrels, shulkers, droppers, dispensers, hoppers, ender chests. Per-type colors, outline/fill opacity, 4 styles, tracers, labels.
- SpawnerFinder: same style engine, wireframe + chat alert.
- AntiVanish: spectator detection (tab list), players looking at you, possible camera-spectating.
- Freecam: detached camera, body frozen, interaction blocked.
- Fly: Velocity or Creative mode, optional Noclip.
- Xray: ore/container whitelist + fullbright.
- Sky: fixed time / time speed, sky color (custom, tint, rainbow), no rain.
- Interface: accent color, dim, logo animation.

## Clock sun and moon
Enable the "Clockwork Clock Sky" resource pack (it is a built-in pack, default on). Textures are generated by `tools_gen_assets.py`.

## If something fails to compile / does nothing
All mixins are `require = 0` and the config is `required: false`, so a changed Mojang method only disables that one feature (see latest.log).
Version-sensitive spots: `gui/Draw.java` (GuiGraphicsExtractor calls), `ClockworkClient` (ResourceLoader / KeyMapping.Category),
`BlockMixin` (Xray), `LevelMixin` / `ClientLevelMixin` (Sky), `KeyboardInputMixin` (Freecam).

## Build without Gradle
Install JDK 25, launch Fabric 26.2 once (so the game jars exist) and put Fabric API in your mods folder, then run
`./build.sh` (Linux/macOS) or `build.bat` (Windows). Optional args: path to `.minecraft`, path to the Fabric API jar.
It compiles against the vanilla 26.2 jar (unobfuscated, so no mappings needed) and writes `clockwork-1.0.0.jar`.

## Build in the cloud (no local setup)
Create a free GitHub repo, upload the contents of this folder, open the Actions tab, and run "build".
Download `clockwork-jar` from the finished run and drop the jar into your mods list.
